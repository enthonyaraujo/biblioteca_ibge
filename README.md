# Atividade 03

Esta pasta contém uma biblioteca em C para consultar municípios brasileiros usando a API do IBGE.

## Conteúdo

- `src/`: código-fonte e cabeçalho da biblioteca;
- `sample/`: exemplo de programa que utiliza a biblioteca;
- `docs/`: instruções de uso, fluxogramas e descrição da atividade;
- `Makefile`: comandos para compilar o projeto;
- `biblioteca_ibge.zip`: pacote compactado da biblioteca.

Para mais informações, consulte os arquivos dentro de `docs/`.

## Ordem de leitura

1. `docs/como_usar.md`: explica como compilar, instalar e utilizar a biblioteca IBGE em um programa C.
2. `docs/atividade.md`: apresenta a atividade proposta, suas regras e os exercícios envolvendo municípios, grafos e rotas.
